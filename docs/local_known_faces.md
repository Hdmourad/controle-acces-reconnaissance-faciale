# Ajout local des visages connus

## Objectif

Le système utilise le dossier `data/known_faces` pour charger les visages des utilisateurs autorisés.

Les images placées dans ce dossier servent uniquement au fonctionnement local du prototype.

## Exemple

Pour ajouter un utilisateur autorisé, ajouter une image locale :

```text
data/known_faces/Mourad_Hadji.jpg
